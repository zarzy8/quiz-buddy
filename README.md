# 复习出题 · Review quiz

给一份学习文件，就能复习或刷题。

1. 你发一个文件（笔记、讲义、教材 PDF、试卷、题库）
2. 它先判断：**复习资料** 还是 **题库**，并问你确认
3. 复习资料 → 再问「总结要点并出题」还是「只出题」
4. 题库 → 直接开考，一次一题
5. 答完给：总题数、错题数、准确率、每道错题的题目 / 你的答案 / 正确答案 / 解析

## 两种答题界面

- **答题卡片**：聊天里一次一题，选 A/B/C/D 即判分，答错当场给正确答案和解析。
- **独立窗口**：卡片不显示、或你想要「小程序」那种界面时，起一个本地网页窗口，点选项即判分，进度和错题在页面上实时更新。

## 安装

- **插件市场**：搜索 `复习出题` 或 `review quiz`，点安装；或
- **本地目录**：插件 → 添加插件 → 选这个包的目录。

装好后**开一个新会话**，技能目录里会出现 `review-quiz`。

## 用法

直接在对话里 @ 文件，或者只把文件发进来：

```
@我的笔记.pdf 帮我总结并出题
```

```
@题库.docx 开始考试
```

也可以点名：`用 review-quiz 处理这个文件`。

## 它不会做什么

- 不会替你编造文件里没有的内容：扫描版 PDF 没有文字层时会直说读不到
- 出题阶段不会提前给答案
- 不会把你的文件上传到任何地方；独立窗口只监听 `127.0.0.1`

## 依赖

- 读 `.docx` / `.pptx` / `.xlsx` / `.pdf` 依赖宿主的 `office` 技能
- 独立窗口模式需要本机有 Python 3（只用标准库，不装任何包）
